# Учебный репозиторий для домашней работы

Материалы для самостоятельной работы по системе контроля версий Git после
практического занятия «Практика 2.2»: тексты об ИКТИБ — Институте
компьютерных технологий и информационной безопасности ЮФУ (г. Таганрог),
данные, настройки и учебные программы на языке C.

Условия домашней работы приведены в отдельном документе. Работа не сдаётся
на проверку; назначение — тренировка перед контрольной работой.

## Состав

| Каталог | Содержимое |
|---------|------------|
| `text/` | Памятки и объявления (Markdown) |
| `data/` | Списки и расписания (CSV) |
| `config/` | Файлы настроек (INI) |
| `algorithms/` | Учебные программы на языке C |
