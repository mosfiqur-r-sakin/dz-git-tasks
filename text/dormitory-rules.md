# Правила проживания в общежитии студенческого городка ЮФУ (памятка)

Общежития Таганрогского кампуса ЮФУ закреплены за управлением студенческого
городка. Заселение иногородних первокурсников ИКТИБ проводится по направлению
дирекции института в дни зачисления.

## Пропускной режим

Общежитие открыто с 6:00 до 23:30. После 23:30 вход по пропускам
с письменным объяснением причины позднего возвращения. Комендантский
час для первокурсников в адаптационный период не продлевается —
планируйте вечера заранее.

## Гости

Гости допускаются с 10:00 до 22:00 по предъявлении документа,
удостоверяющего личность, и с согласия соседей по комнате.

## Порядок в комнатах

Уборка — по графику, который комната составляет сама. Тихий час —
с 14:00 до 15:00, ночное время (после 23:00) — только тихие занятия.
Электрочайники и обогреватели — только заводского изготовления
и только под присмотром.

## Кухня и постирочная

Кухни открыты с 7:00 до 23:00. Помойте за собой посуду — это правило,
которое спасло больше дружб, чем любые советы. Постирочная работает
по записи у коменданта.
